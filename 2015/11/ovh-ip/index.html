Дополнительные IP

Сейчас, на октябрь 2015 ситуация такова:

  • до 16 IP можно покупать на любой VDS, плата разовая
  • до 16 IP можно покупать на любой SYS сервер, плата разовая, 17 18 19 и последующие до 256 — помесячно
  • до 256 IP можно покупать на любой основной конфиг из OVH сайта, плата разовая

Сети IP можно переносить с сервера на сервер. Именно дополнительные.

  • если покупаешь 256 — то перенос сразу 256
  • если покупаешь 32 + 32 + 32 + 32 + 64 + 64 — то можешь перемешать их как угодно, 32+32 на один сервер, 64+64 на другой и т.д.

Можно мигрировать с VDS и SYS сервера — например ресурсы стали слабые, SYS не хватает, пошел купил мощный дедик, перенес ip.

1 IP стоит 2 евро, т.е. по текущему 150р

Сеть из 256 будет стоить — 38400р разово

Если абузы приходят — локается конкретный IP, а не вся сеть.
